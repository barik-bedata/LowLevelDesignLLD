# Memory Management (মেমোরি ম্যানেজমেন্ট)

## ১. Logical vs Physical Address (লজিক্যাল এবং ফিজিক্যাল অ্যাড্রেস)
*   **Logical Address (Virtual Address):** প্রসেস যখন রান হয়, তখন CPU যে অ্যাড্রেস জেনারেট করে। CPU মনে করে প্রসেসটি মেমোরির 0 নম্বর অ্যাড্রেস থেকে শুরু হয়েছে। এটি আসলে কাল্পনিক।
*   **Physical Address:** RAM বা Main Memory তে আসলেই ডাটাটি যেখানে আছে তার ঠিকানা। 
*   **Memory Management Unit (MMU):** এটি একটি হার্ডওয়্যার ডিভাইস যা লজিক্যাল অ্যাড্রেসকে ফিজিক্যাল অ্যাড্রেসে কনভার্ট (Translate) করে।

---

## ২. Fragmentation (ফ্র্যাগমেন্টেশন - মেমোরি নষ্ট হওয়া)
*   **Internal Fragmentation:** যখন প্রসেসকে মেমোরির একটি নির্দিষ্ট সাইজের ব্লক দেওয়া হয়, কিন্তু প্রসেসটি তার চেয়ে ছোট হয়, তখন ব্লকের ভেতরের বাকি অংশটুকু অব্যবহৃত থেকে যায় বা নষ্ট হয়। একে ইন্টারনাল ফ্র্যাগমেন্টেশন বলে (Paging এ এটি হয়)।
*   **External Fragmentation:** মেমোরিতে সব মিলিয়ে যথেষ্ট পরিমাণ খালি জায়গা আছে, কিন্তু জায়গাগুলো এক সাথে (Contiguous) নেই, বরং ছোট ছোট টুকরো হয়ে ছড়িয়ে আছে। ফলে বড় কোনো প্রসেস মেমোরিতে ঢুকতে পারে না। (Segmentation এ এটি হয়)।

---

## ৩. Paging এবং Segmentation (পেজিং ও সেগমেন্টেশন)
দুটোই External Fragmentation দূর করার টেকনিক। এখানে প্রসেসকে মেমোরিতে কন্টিনিউয়াস (একটানা) রাখতে হয় না।

*   **Paging (পেজিং):**
    *   মূল প্রসেস (Logical Memory) কে সমান সাইজের ছোট ছোট পেজ (Pages) এ ভাগ করা হয়।
    *   RAM (Physical Memory) কেও সমান সাইজের ফ্রেম (Frames) এ ভাগ করা হয়। (Page Size = Frame Size)।
    *   প্রসেসের যেকোনো পেজ RAM এর যেকোনো খালি ফ্রেমে বসানো যায়।
    *   **MCQ Point:** পেজিং এ External Fragmentation হয় না, কিন্তু Internal Fragmentation হতে পারে (শেষ পেজটি ছোট হলে)।

*   **Segmentation (সেগমেন্টেশন):**
    *   প্রসেসকে ইউজারের লজিক অনুযায়ী (যেমন মেইন প্রোগ্রাম একটি পার্ট, ফাংশন একটি পার্ট, স্ট্যাক একটি পার্ট) বিভিন্ন সাইজের সেগমেন্টে ভাগ করা হয়। 
    *   এটি ইউজারের দৃষ্টিভঙ্গি থেকে মেমোরি ম্যানেজ করে।

## ৪. Virtual Memory (ভার্চুয়াল মেমোরি)
অনেক সময় আমাদের গেম বা সফটওয়্যার RAM এর সাইজের চেয়েও বড় হয় (যেমন ৪ জিবি র‍্যামে ৮ জিবি গেম রান করা)। এটি ভার্চুয়াল মেমোরির কারণেই সম্ভব হয়।
*   **কনসেপ্ট:** পুরো প্রসেসকে একবারে RAM এ আনার দরকার নেই। শুধু যে অংশটুকু বা পেজটুকু (Page) এই মুহূর্তে দরকার, সেটুকু Hard Disk থেকে RAM এ আনা হয়। 
*   **Demand Paging:** যখন কোনো পেজের দরকার বা ডিমান্ড হয়, ঠিক তখনই তাকে মেমোরিতে আনা।
*   **Page Fault (পেজ ফল্ট - ইম্পর্টেন্ট):** CPU যে পেজটি রান করতে চাচ্ছে, সেটি যদি ওই মুহূর্তে RAM এ না থাকে (বরং হার্ডডিস্কে থাকে), তখন যে এরর বা বাধা তৈরি হয় তাকে Page Fault বলে। এরপর OS সেই পেজটিকে হার্ডডিস্ক থেকে RAM এ নিয়ে আসে।
*   **Thrashing (থ্র্যাশিং):** যদি সিস্টেমে খুব বেশি প্রসেস থাকে এবং RAM খুব কম থাকে, তবে বারবার Page Fault হতে থাকে। OS প্রসেস রান করার চেয়ে পেজ হার্ডডিস্ক থেকে RAM এ আনা-নেওয়া করতেই বেশি ব্যস্ত থাকে। ফলে সিস্টেম প্রচণ্ড স্লো হয়ে যায় বা হ্যাং করে। একে Thrashing বলে।
